# 🎪 Campus ClubHub — Web Portal

A high-performance student club and event portal built with **React 19**, **TypeScript 5.9**, **Vite 7**, and **Tailwind CSS v4**.

## ✨ Features

- **🔐 Role-Segregated Institutional Authentication**:
  - `*@vitstudent.ac.in` for student registrations, schedules, and passes.
  - `*@vit.ac.in` for organizer / faculty event creation and attendee management.
- **🎟️ Digital Holographic Event Passes**:
  - Clean printable entry passes with real-time SVG QR Code generation for fast-track door verification.
- **📅 Calendar Integration**:
  - One-click Google Calendar sync & downloadable `.ics` files.
- **💬 Interactive Event Details Modal**:
  - Full agenda timeline, event perks (certificates, refreshments), and an interactive FAQ accordion.
- **🛡️ Organizer & Club Lead Console**:
  - Live occupancy and registration KPIs, real-time student attendee rosters, attendance CSV export, and event publishing modal.
- **🔍 Fast Search, Categories & Sorting**:
  - Search by title, tags, or club with sorting options for date, popularity, and available seats.

## 🚀 Development Setup

```bash
# Install dependencies
npm install

# Start Vite local development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
