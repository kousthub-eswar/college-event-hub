# 🎪 Campus ClubHub

This repository contains **Campus ClubHub**, a modern, responsive web portal for college students to discover and register for clubs, chapters, and campus events.

## 📂 Project Structure

- `club-events-portal/`: The main React 19 + TypeScript + Vite project powered by Tailwind CSS v4.
  - Setup instructions, tech stack, and structure details are located inside the [portal's README.md](file:///c:/Users/sasim/Desktop/Club_Events/club-events-portal/README.md).

## 🚀 Getting Started

To get the app running locally:

```bash
# Navigate to the portal directory
cd club-events-portal

# Install dependencies
npm install

# Start the local development server
npm run dev
```

The app will be running at `http://localhost:5173`.
